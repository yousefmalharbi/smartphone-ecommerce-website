# Smartphone E-Commerce Website

A responsive Arabic smartphone e-commerce website developed as a three-member university team project for **CIT 230 – Web Design** at the **University of Tabuk**.

🌐 **Live Demo:** https://smartphone0.netlify.app

## Overview

The project is a multi-page e-commerce website designed to showcase smartphone products through a clean, responsive interface. It includes product listings, detailed specification pages, a validated contact form, and a dynamic team page.

## Features

- Responsive Arabic user interface
- 10 HTML pages
- Six smartphone product detail pages
- Product specification tables
- Validated contact form
- Consistent navigation across pages
- Product cards with order and details actions
- Embedded video on the home page
- JavaScript-based randomized team-member display
- Public deployment on Netlify

## Technologies

- HTML
- CSS
- JavaScript
- Netlify
